\# 🛡️ AegisVault Ultimate



AegisVault Ultimate è un password manager desktop moderno, open source e orientato alla massima sicurezza, sviluppato in Python utilizzando \*\*CustomTkinter\*\* e standard crittografici di livello militare.



\## 🚀 Caratteristiche Principali



\* \*\*Crittografia Avanzata:\*\* Utilizza \*\*AES-GCM a 256-bit\*\* combinato con la derivazione della chiave \*\*PBKDF2-HMAC-SHA512\*\* (600.000 iterazioni) per proteggere i dati.

\* \*\*Database Isolati (`.aegis`):\*\* Ogni utente gestisce un database proprietario ed esteso con formato `.aegis`, leggibile ed accessibile esclusivamente inserendo la corretta Master Password.

\* \*\*Auto-Lock di Sicurezza:\*\* Sistema di blocco automatico integrato in caso di inattività prolungata per proteggere l'account se ci si allontana dal PC.

\* \*\*Generatore di Password Sicure:\*\* Generatore integrato di chiavi casuali ad alta complessità.

\* \*\*UI Moderna:\*\* Interfaccia grafica dark-mode fluida e curata grazie a CustomTkinter.
